Selector cases

Each case reports below when its target is clicked or typed into. Iframes are sandboxed without allow-same-origin, so they behave as cross-origin.

1. Normal element

button[data-test-id="normal-btn"]

2. Element in a cross-origin iframe

iframe#plain-frame << button[data-test-id="frame-btn"]

3. Element in a shadow root

shadow-host#sh || button[data-test-id="shadow-btn"]

4. Nested shadow roots

outer-host#outer || inner-host || button[data-test-id="nested-btn"]

5. Iframe inside a shadow root

widget-host#widget || iframe[title="Widget Frame"] << button[data-test-id="frame-btn"]

6. Shadow root inside an iframe

iframe#shadow-frame << frame-host || button[data-test-id="frame-btn"]

7. Text input in a shadow root

input-host#ih || input[data-test-id="shadow-input"]
